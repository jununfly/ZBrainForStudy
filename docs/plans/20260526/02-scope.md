# 范围和边界澄清

## 改写范围

### 包含内容

| 模块 | 文件数量 | 说明 |
|------|----------|------|
| 核心引擎 | ~479 个 TS 文件 | src/core/ 下所有内容 |
| CLI 命令 | ~40 个命令 | src/commands/ 下所有内容 |
| MCP 服务器 | ~10 个文件 | src/mcp/ 下所有内容 |
| Web 管理界面 | ~150 个 TSX 文件 | admin/ 下所有内容 |
| 技能系统 | ~40 个技能 | skills/ 下所有内容 |
| 测试 | ~892 个测试文件 | 转换为 Rust 测试 |

### 排除内容

| 内容 | 说明 |
|------|------|
| `.git/` | Git 历史保持不变 |
| `node_modules/` | Node 依赖，不迁移 |
| `bun.lock` | Bun lockfile，不迁移 |
| `.gbrain/` | 本地用户数据，不迁移 |
| `~/.gbrain/` | 用户个人数据，不迁移 |
| 已编译 WASM | src/assets/wasm/ 保持作为资源 |

## 技术边界

### 保持兼容的接口

```
- BrainEngine trait（原接口）
- Operation contract（操作契约）
- CLI 命令行参数
- MCP 工具协议
- 数据库 schema（保持兼容）
- 配置文件格式
```

### 必须重写的部分

```
- TypeScript 运行时代码
- Bun 特定的 API 调用
- Node.js 标准库调用
- WebAssembly 加载逻辑
- 异步运行时（从 Bun 转换为 Tokio）
```

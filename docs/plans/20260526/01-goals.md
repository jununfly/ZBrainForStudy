# 改写目标确认

## 主要目标

### 1. 语言转换
将整个 GBrain 项目从 TypeScript 完整改写为 Rust

**理由**:
- 更好的性能和内存安全
- 更小的二进制体积
- 更强的类型系统
- 更好的并发支持

### 2. 品牌重命名
所有 `gbrain` 改为 `zbrain`

**涉及范围**:
- 项目名称
- 命令名称
- 配置文件
- 环境变量
- 文档注释
- 输出信息
- 代码中的标识符

### 3. 添加本地 Web 界面
提供可运行的 Web 页面，用于增删改查知识库内容

**功能需求**:
- 页面列表和搜索
- 页面查看和编辑
- Markdown 渲染
- 实体关系图
- 搜索功能（混合 RAG）
- 文件管理

### 4. 单例引擎模式
确保全局唯一引擎实例，防止多实例操作写坏数据

**技术要求**:
- 使用 Rust 的 `OnceCell` + `Arc<Mutex<Engine>>`
- 线程安全
- 初始化一次，全局访问
- 防止重复初始化

### 5. 测试保持
所有现有测试继续生效并通过 `cargo test` 等效验证

**测试策略**:
- 保持测试逻辑不变
- 转换测试框架从 Bun/Vitest 到 Rust 测试框架
- 保持测试覆盖率
- 新增测试覆盖 Web 界面和单例模式

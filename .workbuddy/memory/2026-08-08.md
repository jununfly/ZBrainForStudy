- 取回已删 TS 原文 `git show bcafcafd^:src/core/search/eval.ts` 对账。
- 新增 `crates/zbrain-core/src/search/eval.rs`：4 纯指标 `precision_at_k`/`recall_at_k`/`mrr`/`ndcg_at_k` + 类型 `EvalQrel`/`EvalQrelFile`/`EvalConfig`(`EvalStrategy`)/`QueryResult`/`EvalReport` + `parse_qrels`（内联 JSON 或文件路径，支持 array 与 `{version,queries}` 两形式）+ `run_eval` 编排 + `keyword_search_slugs` 便利函数。`search/mod.rs` 加 `pub mod eval` + 导出。

- **验证**：`cargo test -p zbrain-core --lib search::eval` **13 passed / 0 failed**（含真实 InMemoryEngine keyword 集成 + parse_qrels 文件往返 + 4 指标 golden case，如 nDCG 非理想排序 0.7968、P@5=2/5、R@5=1.0）。默认 feature 下 `cargo build -p zbrain-core` 绿（gated 块无）。

### 关键决策

1. **Operation Trait 架构**: 采用双 trait 设计 - `TypedOperation` (泛型) + blanket `impl Operation` (对象安全) 实现 registry 动态分发
2. **错误处理**: 每个 Operation 独立的参数验证错误，通过 `ValidateParams` trait 统一实现
3. **序列化策略**: 新增 `serde::Serialize` derive 到 `PageVersion`、`RawData` 等类型，保持 camelCase 命名与 TS 兼容
4. **TDD 模式**: 垂直切片开发，一个 operation → 一个测试 → 实现，而不是批量写测试或批量写实现

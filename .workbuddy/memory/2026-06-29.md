### 关键决策

1. **Operation Trait 架构**: 采用双 trait 设计 - `TypedOperation` (泛型) + blanket `impl Operation` (对象安全) 实现 registry 动态分发
2. **错误处理**: 每个 Operation 独立的参数验证错误，通过 `ValidateParams` trait 统一实现
3. **序列化策略**: 新增 `serde::Serialize` derive 到 `PageVersion`、`RawData` 等类型，保持 camelCase 命名与 TS 兼容
4. **TDD 模式**: 垂直切片开发，一个 operation → 一个测试 → 实现，而不是批量写测试或批量写实现

## Postgres 迁移兼容性修复 (6月30日凌晨)

### 修复内容

1. **SQL 语句分割器重写** (`postgres.rs:45-150`)
   - 原朴素 `split(';')` 无法处理 PL/pgSQL 中的美元引用字符串
   - 实现完整 SQL 语法感知分割器：
     - `$tag$...$tag$` 美元引用字符串跟踪
     - 单引号字符串转义处理
     - `--` 行注释和 `/* */` 块注释跳过
     - 仅在引号/注释外的分号处分割

2. **类型对齐修复**
   - `pages.id` 是 `BIGSERIAL` (i64)，所有引用字段从 `INTEGER` → `BIGINT`
   - 修复文件：`0008_files.sql` (page_id)、`0009_raw_data_and_page_versions.sql` (page_id + id)
   - Rust 代码中所有 `i32` page_id 读取改为 `i64`
